# 면접 리허설

자기소개서를 바탕으로 예상 질문을 만들고, 가상의 면접관 세 명과 꼬리질문·압박 모의 면접을 하면서
카메라와 음성으로 말하기 습관과 태도를 분석하는 면접 연습 사이트입니다.

## 쓰는 법

1. 컴퓨터의 크롬이나 엣지에서 사이트를 엽니다.
2. 오른쪽 위 **설정·백업**에서 Anthropic API 키를 넣습니다. (질문 생성, 꼬리질문, 평가, 뉴스 검색에 필요)
3. 지원 폴더를 만들고 자기소개서를 넣은 뒤 **모의 면접**을 시작합니다.
4. 처음 시작할 때 브라우저가 카메라·마이크 권한을 물으면 허용합니다.

## 개인정보

- 모든 데이터(폴더, 자소서, 기록, API 키)는 **이 브라우저의 저장소에만** 저장됩니다. 서버로 올라가지 않습니다.
- 녹화 영상은 브라우저 안에만 있고, 페이지를 닫으면 사라집니다. 필요하면 ‘녹화 영상 저장’으로 내려받으세요.
- AI 분석을 할 때만 질문·답변 내용과 답변 중 찍은 사진 몇 장이 Anthropic API로 전송됩니다.
- 음성 받아쓰기는 브라우저의 음성 인식 기능을 쓰며, 크롬은 음성을 Google 서버에서 처리합니다.
- API 사용료는 Claude 구독과 별도로 Anthropic 계정에 청구됩니다.

## 개발

- 화면 코드는 `src/app.html` 하나입니다. 같은 파일을 claude.ai 아티팩트로도 게시합니다.
- `./build.sh`를 실행하면 `src/app.html`을 감싸 `index.html`을 만듭니다. GitHub Pages는 `index.html`을 그대로 보여 줍니다.
